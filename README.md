# 🔴 RedOps v1

**RedOps** is a Python-based cybersecurity toolkit designed to bring essential reconnaissance and network utilities together in one command-line interface.

The project is built as a hands-on learning experience to improve my Python programming skills and practical understanding of cybersecurity that got some tools that would help you guys out.

## ✨ Features

- **DNS Lookup** — Resolve domain names to IP addresses.
- **Target Validation** — Validate and identify IP addresses or hostnames.
- **Endpoint Discovery** — Discover accessible web endpoints using a wordlist.
- **HTTP Status Detection** — Identify responses such as `200 OK`, `401 Unauthorized`, `403 Forbidden`, `301 Redirected`, and `302 Found`.
- **Interactive CLI Menu** — Navigate between available tools through a simple terminal interface.

## 🛠️ Built With

- Python 3
- `socket` — DNS resolution and network operations
- `requests` — HTTP requests and endpoint discovery
- `time` — Delays and terminal processing feedback
- `subprocess` — System command execution where needed


## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/vo1dbyt3/RedOps.git
```

### 2. Enter the project directory

```bash
cd RedOps
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run RedOps

```bash
python3 main.py
```

## 🚀 Usage

1. Launch RedOps from your terminal.
2. Select an operation from the main menu.
3. Enter the requested target or other required information.
4. Review the results displayed in the terminal.

Available operations depend on the current development version.
